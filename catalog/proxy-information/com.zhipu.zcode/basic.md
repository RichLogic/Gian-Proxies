# ZCode：基本信息审阅

基本信息正文固定三行；下面的说明和状态样例用于审阅，不作为额外字段全部显示在 UI 中。

## 显示顺序与来源

| 顺序 | 字段 | 值的来源 |
| --- | --- | --- |
| 1 | Runtime 路径 | Host 的托管 Runtime 安装记录与校验结果 |
| 2 | Runtime 版本 | 当前实际 Runtime 的已核对版本；没有有效安装记录时不以最新版本冒充当前版本 |
| 3 | Proxy 版本 | 当前激活 Proxy 或明确标注开发来源的源码 Proxy；没有则显示未安装 |

名称与图标放在标题，安装操作和进度放在三行之后。Runtime 文件位置与账号配置分开核对。

## 当前发布目标快照

这是 2026-10-20 Catalog 1.31.0 的目标，不是本机安装状态：Proxy **0.4.5**，Runtime **0.17.0**。

目标位置样例：

```text
Gian 安装记录中通过校验的 zcode/agent/zcode.cjs
```

没有通过安装校验时显示“Runtime 未准备”，不要把示例路径当成已验证路径。当前 Runtime 来自随 Proxy 发布的固定源码构建；版本匹配不等于账号配置或真实模型请求已经验证。

## 状态样例

| 状态 | Runtime 路径 | Runtime 版本 | Proxy 版本 | 操作/说明 |
| --- | --- | --- | --- | --- |
| 完全未准备 | Runtime 未准备 | 未检测到 | 未安装 | 通过已签名 Catalog 准备对应 Proxy 与托管 Runtime |
| 有源码 Proxy，无 Runtime | 实际发现结果或未检测到 | 未安装 | 0.4.5，标明开发来源 | 不把源码存在当成认证组合已激活 |
| 已准备，用户配置未完成 | Host 已核对路径 | Host 当前值 | Host 当前值 | 配置/登录是另一检查点，不假报 Ready |
| 正在更新 | 保留旧激活路径 | 保留旧当前版本 | 保留旧当前版本 | 目标变化与进度在操作区显示 |
| 校验失败 | 已知路径可用于诊断，但不能标可执行 | 不冒充兼容 | 当前已知值 | 明确失败原因，禁止用 latest 覆盖当前状态 |

## 不能混淆

- ZCode 的 Proxy 版本、Runtime 版本与 Gian App 版本不是同一个版本号。
- 最新发布版本不等于已安装版本；程序已安装不等于账号/端点配置完成。
- Runtime 安装状态不等于账号配置就绪，多个 Agent 不代表多个隔离账号。
